## Evidence already in the repo

The items below can be cited or exported as-is once the matching policy exists. Vanta's GitHub integration collects most of this automatically.

- `docs/03-engineering/delivery-model.md`: the rulesets, completion bar, promotion and break-glass process.
- `.github/workflows/ci.yml`: the required checks, including the dependency audit.
- `.github/CODEOWNERS` and `tests/mailbox-access-pins.test.ts`.
- `infra/discovery-worker/` (`alarms.tf`, `alerts.tf`, `detection.tf`, `cloudtrail.tf`) and gate G8 in `docs/04-operations/discovery-worker-aws-runbook.md`, for the AWS worker's monitoring.
- `src/lib/log/` with `tests/log/`, for the content-free server logger, and `docs/04-operations/app-observability-runbook.md`, for its owner steps (#474).
- `supabase/migrations/`, which holds the RLS policies (`*_rls_*`), audit-log immutability (`20260625120000_audit_log_immutable`), the hash chain (`20260925100000_audit_hash_chain`) and legal hold.
- `next.config.ts`, which sets baseline security headers (X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy). There is no Content-Security-Policy or Strict-Transport-Security header on `develop` yet (#480).
- ADR-0008 (auth and audit spine), ADR-0015 (agent-seam token signing), ADR-0016 (tenancy and RLS backstop) and ADR-0017 (data residency).
