# Shared copy + voice (all 4 prototypes)

Every visible string must trace to `/docs` and pass the persona test (would it
survive Storm Duncan / an MD). Brand voice: **precise, senior, decisive** —
statements not questions, no hedging, **no em-dashes in visible prose**.

## Positioning line (verbatim)
> The compliance-first M&A intelligence layer for managing directors.

## Three headline claims (in order)
1. **Decisions, not data dumps.** Five ranked acquirers, scored, with a one-line rationale.
2. **Compliance omnipresent.** Every intent and message screened before it executes.
3. **MD-native.** Built for the person who makes the call, not the one who prepares the briefing.

## Anti-Rogo contrast (use where it fits)
- Rogo answers "I want to buy Apple" with a data dump. Conductia surfaces only the key decisions an MD must make on a sell-side deal.

## The deal (canonical)
- **You** are Storm Duncan, MD running the **sell-side** mandate for **Atlassian** (Project Atlas, ATLAS-2026-001).
- Mike Cannon-Brookes is the founder being **evaluated**, never the logged-in user.
- Top fit: **Anthropic 87**. Lower fit reference: **Salesforce 67**. (Deterministic: 55% financial / 45% culture.)

## Honest "live vs vision" labels (Storm will probe)
Tag features so the pitch stays credible:
- **Live now**: scoring + analytical panels, compliance screening (mock verdicts), deal creation, role-based invites, data-room classification, document-view audit trail.
- **Vision / next**: real AI answers in the command bar, automated NDAs, engagement letters, conflict checks, DB-level RLS enforcement of phase-gating.

## Capability labels (use consistent wording)
- Mandate · Acquirers · Deal Team · Data Room · Skills · Audit
- Compliance cascade: **KYC → FINRA → MNPI**
- Verdicts: **Clear · Hold · Blocked**
- Roles: Managing Director · Deal Team · Legal Counsel · Chief Compliance Officer · Administrator · Seller · Buyer · Observer

## Don't
- No em-dashes in prose (use commas or periods). No hedging ("perhaps", "might").
- No emoji as icons (SVG only). Never rename the brand spelling.
- Never claim a vision feature is live.
