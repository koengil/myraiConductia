# Prototypes

Standalone, self-contained HTML prototypes for demos and exploration. These are design artifacts, not production code: they are not part of the Next.js app, the `ConductiaAPI` seam, or the deployed surface. Open them directly in a browser.

- `intelibank_journey.html` — "The full swing": walkthrough of the deal journey for the demo. Generated with Claude.ai, added 2026-06-03.
- [`future-vision/`](future-vision/index.html) — future-vision pitch set for the Storm call: a 2x2 of four standalone prototypes (paradigm × treatment) showing where the platform could go. Open [`future-vision/index.html`](future-vision/index.html) as the launcher; see [`future-vision/README.md`](future-vision/README.md) for the map and capability matrix. Added 2026-06-05.
