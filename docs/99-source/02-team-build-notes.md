# Team Build Notes — 2026-05-19 — Authoritative Scope

### Investment Banking AI Platform Vision

- Building M&A-focused platform for managing directors (not general finance like Rogo)
- Target user: Managing directors making executive decisions on acquisitions
- Demo scenario: Atlassian selling to potential acquirers (Anthropic, Salesforce)
  - Pre-loaded company data to avoid heavy onboarding demo
  - Focus on sell-side M&A process
- Core value: Surface key decision-making information, not overwhelming data dumps
  - Compliance-first infrastructure layer
  - Financial scoring matrix
  - Culture/psychological fit matrix (vision, mission, founder fit, headcount, industry alignment)

### Platform Architecture & Features

- Skills marketplace concept for M&A decision-making
  - 4-5 skills in demo, one premium skill requiring paid plan
  - Each skill performs data transformation through compliance layer
  - Drag-and-drop interface for different analysis cuts
  - Skills harnesses customizable per user/company
- Multi-user compliance demonstration
  - Team member profiles (MD, CFO, M&A advisor)
  - Real-time compliance checks on communications
  - Animation showing compliant vs non-compliant messages
- Scoring system for potential acquirers
  - Anthropic: 87 score (AI-native fit)
  - Salesforce: 67 score (traditional SaaS, not AI-focused)
- Visual comparisons with competitor companies (Figma, Canva references)
