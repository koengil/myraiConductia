# Founder Call — Storm — Vision & Strategy Notes

### Investment Banking AI Platform Vision

- End goal: fully automated investment bank (5-10 year vision)
  - Client types "I want M&A advice" → everything handled automatically
  - Market opportunity: hundreds of billions (Goldman, JP Morgan combined)
- Current focus: compliance-first infrastructure layer
  - Every skill/agent must pass through compliance checking
  - Regulatory compliance (FINRA) as core differentiator vs competitors
- Skills marketplace concept (long-term)
  - Individual skills can call other skills
  - Revenue sharing for skill creators
  - Apple App Store model for financial services

### Compliance Layer as Core Product

- Primary competitive advantage over Rogo ($2B valuation, PowerPoint-focused)
  - Rogo lacks compliance infrastructure
  - Charges per analyst (misaligned incentives)
  - Claude now offers similar PowerPoint generation
- Compliance infrastructure requirements:
  - All emails must route through platform
  - Text/WhatsApp monitoring via business accounts
  - Real-time compliance checking before sending
  - Former FINRA examiners as advisors
- Market validation: multi-billion dollar fines for non-compliant communications
  - Investment banks losing analysts to compliance violations
  - Reputational damage from leaked inappropriate messages

### Target User & Workflow

- Primary user: Managing Directors (not junior analysts)
  - Most compliance issues occur at senior level
  - Focus on knowledge work vs administrative tasks
- Initial workflow: first call to pitch preparation
  - Pre-call company research with buyer analysis
  - Meeting transcription and analysis
  - Pitch deck generation based on client psychology profiles
  - All outputs filtered through compliance layer
- Psychological profiling integration
  - Client personality assessment (visual vs numbers-focused)
  - Tailored pitch recommendations
  - Customized question suggestions for meetings

### Technical Architecture & Orchestration

- Master agent as conductor routing to specialized skills
- Reinforcement learning approach
  - Compliance feedback improves system over time
  - False positive reduction through user corrections
- Skill quality management concerns
  - Prevent skill bloat and regression
  - Careful process for self-teaching agent updates
- Marketplace liability questions
  - Responsibility for third-party skill compliance failures
  - Need clear ownership structure
