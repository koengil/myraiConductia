The Horizontal/Vertical Map

One picture of the platform. The horizontal rails carry every deal through five phases and sixty-five steps. The vertical skills do the work at each step. Futureproofing builds the rails and the always-on layer. RTS builds the skills.

Futureproofing builds (the rails + always-on) RTS builds (the step-skills) ★ Priority build (16 of them) Who runs each step: agent · agent then human approval · human leads and the agent checks · human

Before the rails: Gate 0

Four actions at deal creation, before Step 1, every time. A mandate can enter mid-lifecycle: Gate 0 confirms where the rails begin. Every step below can be skipped with logged approval, edited after completion (outputs are versioned), and is assigned to a human or an agent with a deadline or priority tag.

Three layers

The platform is built in three layers. Click any item for detail.

Layer 1 — Platform (always-on)

Runs no matter which deal or step you're on: security and isolation, the audit log, access control, storage, search, communications monitoring, cost and time metering, the knowledge graph. Built by Futureproofing.

Layer 2 — Horizontal workflow rails

The engine that carries a deal through the 65 steps: orchestration, the next-step recommender (after each step it suggests the best next step, with the full list to pick from), quality-control gates, and verification. Built by Futureproofing.

Layer 3 — Vertical step-skills

The skill that does the actual work at each step — the 65 steps on the rail above. One skill per step. Built by RTS.

Compliance and trust — the spine

Not a fourth layer. The spine runs through all three: every step, in every layer, is screened, gated, and logged.
