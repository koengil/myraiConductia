## 4. Subagent dispatch policy (D21, carried)

When a phase explicitly says `Parallel (file-disjoint, conductor integrates)`:

1. Conductor partitions the file set so no two subagents write to the same path.
2. Each subagent receives: explicit file list, the relevant section of `MERGE-REVIEW.md`, the source B paths to read, the destination A paths to write, the brand/voice policy reference, and the verify-gate snippet for its slice.
3. Subagents are read-only on B and write-only inside their assigned slice in A. **Subagents never run `git stash`, `git reset`, `git checkout`, `git commit`, `git push`, or any worktree-mutating op.**
4. Conductor integrates returned diffs, runs the full verify gate, then commits to the feature branch (only after explicit per-commit authorization from the owner).
5. If two subagents need to touch the same file, the work is sequentialized, not parallelized.
