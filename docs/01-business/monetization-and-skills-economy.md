# Monetization & Skills Economy — Conductia

This document covers how Conductia makes money: the near-term paid-plan model and the
longer-term skills marketplace.

---

## 1. Near-term: plans gated by skill access

The monetization model is plan-based, with access to skills as the differentiating
dimension. Users on a base plan can access a defined set of skills; premium skills
require an upgraded plan.

In the sandbox demo, this is made concrete: the hero canvas has five skills — four on
the demo plan, one premium-locked — and the premium skill prompts an upgrade when a user
tries to access it. The intent is to demonstrate the business model directly to
Storm during the demo: a locked skill makes visible that skill access is the value
metric, not analyst seats (which is the Rogo model).

## 2. Longer-term: the skills marketplace

The skills marketplace is the platform's intended monetization endgame: third-party skill
sales generate a platform revenue share, and skill access becomes the lever that gates plan
tiers as the catalogue grows. Identified exit paths: acquisition by Rogo or a major-bank
buyout.

See [../00-vision/north-star.md](../00-vision/north-star.md) § 4 for the marketplace as
product vision.
