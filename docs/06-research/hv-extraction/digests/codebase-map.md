## Design system today

- **Token source of truth:** `src/app/globals.css` (1,086 lines), pure Tailwind 4 CSS-first (no `tailwind.config.*`). Ink `#0E1B3A` + secondary/tertiary; surfaces white/`#ECEEF2`/`#F4F5F8`; accent `#2E6FA3` steel blue (history: teal→gold→blue); semantics positive/negative/**hold** (`--hold`, the third compliance verdict, ADR-0003); navy canvas `#0A1228` + cinematic gradients + 48px texture grid; brand shield orange `#f08d2f` palette-independent.
- **On-dark ladder** (globals.css:216-232): `--ink-on-dark(-secondary/-tertiary)` + `--on-dark-fill-03…16`/`--on-dark-stroke-10…16` via `color-mix` — the workhorse of every navy surface; dark-mode fills re-derived from accent so edges never white-cast.
- **Palette × style-mode matrix** (globals.css:333-847; `src/lib/theme/palette.ts`): 4 palettes (`navy` default, `gold-navy`, `mono`, `navy-orange`) × 2 modes (`dark` default, `light`) via `data-palette`/`data-style-mode` on `<html>`. Light mode **remaps the on-dark aliases** (`--canvas-bg → --surface`, `--ink-on-dark → --ink`) so on-dark call sites never fork — load-bearing trick. Flash-of-wrong-theme prevented by an inline bootstrap script (`layout.tsx:56-62`). Shell (`--shell-*`, `--sidebar-*`) and mandate-dashboard (`--mandate-*`, `--panel-*`) token layers sit above the palette.
- **Typography:** reality is single-sans — `--font-bank` = Plus Jakarta Sans; `--font-sans` AND `--font-display` both alias it (globals.css:51-54). **Inter is gone; Fraunces is loaded but unreachable** (only referenced via `--font-display`, which no longer resolves to it). CLAUDE.md/README's "Fraunces/Inter/Geist Mono" trio is stale. IB-terminal scale (ADR-0006): 13px body, `--text-xxs 10 … 2xl 28`. Semantic ramp (`.bank-heading`, `.eyebrow`, `.data-xl`, `.mono-legal` …) lives in `@layer components` **specifically so `text-[…]` utilities win** — the fix for historical invisible-text-on-navy bugs; any new semantic classes must stay layered.
- **Contrast contract:** light surfaces → `--ink*`; navy surfaces → `--ink-on-dark*`; enforced by the `surface: 'light'|'dark'` prop on every atom, plus surface utilities (`.surface-cinematic`, `.surface-canvas-stage`) that set bg AND color together. Zero tests pin the contract.
- **Spacing/radii/elevation:** 4px grid `--space-1…24`; radii input/button 10, card 16, pill (soft native-app feel); `--elev-0…3` light + `--elev-dark-0…2` + `--elev-float` console shadow + neon glows.
- **Motion** (`src/components/_shared/motion.ts` + `docs/04-brand/motion-language.md`): three named product motions — Compliance Pulse, Skill-Transform Stream ("the motion is the product"), Score Reveal — plus shell choreography constants; `prefers-reduced-motion` honored everywhere.
- **Components** (~11k LOC TSX): atoms `Button`/`Badge`/`Pill`/`Card`/`ScoreDial`/`SegmentedControl`/`AvatarInitials` — hand-rolled, token-driven, accessible. Known bugs: `Button.tsx:43` light-primary `bg-accent text-black` (gold legacy — black-on-blue latent contrast bug); SegmentedControl dark-styling hardcoded. Compliance surfaces (`ComplianceRibbon` — contract-frozen 5-state instrument, `ScreeningOverlay`, `CommandBar` with frozen KYC→FINRA→MNPI cascade). Analysis panels (FootballField/CultureRadar/ScoreBreakdown/CultureMatrix/SynergyStressTest/FounderRead, NeonPanel/GlowMetricCard/ScoreGauge). The league table is inlined in `acquirers/page.tsx:301-665`, not reusable.
- **Debt:** three icon dialects (7-glyph brand set in `brand/icons/`, lucide in Sidebar, bespoke SVGs in AppNav); orphans `shell/AppRail.tsx`, `ui/demo.tsx` (the only reason `@radix-ui/*` deps exist), vestigial Inter OpenType settings; two type scales coexist (~363 raw Tailwind text utilities vs ~293 tokenized); `docs/04-brand/visual-language.md` stale twice over (teal accent, 15px, Fraunces/Inter); landing's `--l2-*` layer is a second aesthetic dialect with hardcoded palette.

## Data & orchestration seam

- **The seam:** UI talks only to `ConductiaAPI` (`src/lib/api/types.ts:136-152`), lazy singleton `getApi()` (`src/lib/api/index.ts`) → `MockConductiaAPI` (`src/lib/api/mock.ts`). 13 methods: content reads (seller/acquirers/peers/skills/team), deterministic scoring (`src/lib/scoring/composite.ts:89` — Anthropic 87 / Salesforce 67, editable weights per ADR-0002, `computeDealReadiness` at `:107`), `runSkill(skillId, acquirerId)` → locked | `SkillRunData` discriminated union (`dataKind: 'company'|'cultureFactors'|'compositeScore'`, client maps dataKind→panel per ADR-0005), compliance (`checkMessageCompliance`/`sendMessage` → pure rule pack `screenMessage`, `src/lib/compliance/screen.ts:79`: promissory→blocked+rewrite, MNPI/$-valuation→hold), and 4 Phase-D analytical panels (valuation, synergy, founder read, culture matrix via `fixtures.ts:491`). Fixtures: Atlassian seller, 5 acquirers with `fitInputs`, 5 skills (ids are a hard contract with `docs/02-product/skills-catalog.md`). Session store (`src/lib/session/store.ts`): compliance status (single-ribbon dispatch), panels, selectedAcquirerId; legacy `mandateCompany` unused.
- **/api/v1 platform contract** (ADR-0008, beside the seam, never inside): 14 route files under `src/app/api/v1/`; every handler self-authenticates via `requireApiUser()` (`src/lib/api/v1/http.ts:9`) then uses a service-role admin client; authorization is app-layer predicates in `src/lib/api/v1/access.ts` (`userCanAccessDeal`, `userIsDealMd`, `canManageDealMembers`, `listDealsForUser`); deal codes auto-minted `PREFIX-YEAR-NNN` (`http.ts:55`); audit rows written inline (deal_created / grant / revoke / view). Constants in `src/lib/constants/*` mirror SQL CHECK enums; `tests/constants-schema-sync.test.ts` locks parity both directions.
- **Supabase schema** (9 migrations, `supabase/migrations/`): feature_flags; Phase-1 core `20260604100000_permissions_schema.sql` — companies, users (id = auth.users.id, firm_role, 6-way department), roles (8 seeded), **deals (status `intake|active|paused|closed`)**, deal_parties, **deal_memberships (with `phase int default 0` + `access_scope jsonb`)**, **documents (classification 1-4, `min_phase`)**, audit_log; company membership axis + last-director invariant + removal cascade; RLS read policies (defense-in-depth; buyer min_phase gate deferred to Phase 2); **audit_log physically append-only** (`20260625120000`, SEC 17a-4 framing); **legal hold** (`20260629120000`, `place_legal_hold()`/`lift_legal_hold()`). Tenancy is a constant (`DEV_TENANT_ID`, `src/lib/db/tenant.ts`). Seeds: `scripts/seed-data.ts`/`seed-users.ts` — 10 per-role dev accounts `<slug>.intelibank@dev.com`, 2 deals, class-4 docs, one delegated seat.
- **Orchestration spine** (`src/lib/orchestration/`, PR #42): deterministic durable state machine, not an LLM planner. `Job` primitive (`types.ts:24` — goal, dealId, stakes, completionCondition); `selectWorkflow()` regex-matches to a `WorkflowSkeleton` — **only `prepare-teaser` exists** (`workflows/teaser.ts`); machine `INTERPRET → PLAN → [AWAIT_PLAN_CONFIRM] → RESEARCH → DRAFT → COMPLIANCE_SCREEN → [AWAIT_SIGNOFF] → COMPLETE`, terminals BLOCKED/HALTED/FAILED (`orchestrator.ts:135-221`); sealed `ContextEnvelope` push-not-pull with scope/phase/classification gates mirroring DB rules (`envelope.ts`); uniform `CapabilityAgent` contract with mandatory `report` side channel (`contract.ts`); compliance supervisor (pre-send gate + rogue-agent HALT, `compliance/supervisor.ts`); model router + `TokenMeter` (`model-router.ts`); full audit replay via `reconstruct(events)` (`audit.ts`). Store is `InMemoryJobStore` behind a `JobStore` interface — **the Supabase-backed store is the designed drop-in, not built**. `scripts/demo-spine.ts` runs headless.
- **Rail domain model** (`src/lib/rail/`, PR #62): `DEAL_RAIL` — **7 phases (0-6, each mapped to a `deals.status`) / 26 steps** (`dealRail.ts:89-464`); `RailStep {owner, actor: human|agent|both, skill (free-text label), reality: live|schema|planned, agentFeatures}`; **two orthogonal axes**: `reality` hand-set (7 live / 7 schema / 12 planned) vs `state` derived from a progress cursor (`stateForIndex`, `railProgress` — never stored per step). `STEP_FEATURES` map (`dealRail.ts:472`) ≈2 features/step; always-on split deal vs portfolio (`dealRail.ts:937-1009`); `estimateTokens` (`:1016`). `FixtureDeal` (`deals.ts:1-7`) **deliberately mirrors the `POST /api/v1/deals` row so the swap is mechanical**; `cursorStepId` is the one field with no DB home; deals + token ledger persist in localStorage (`ib-fixture-deals`, `ib-deal-tokens`).
- **The gaps a rails model must fill:** no persisted step/rail state (no `deal_steps` table; cursor in localStorage); no step↔skill join (rail `skill:` prose, seam `Skill.id`s, and workflow names are three unlinked vocabularies); one workflow skeleton for 26 steps; no persistent JobStore (runs never reach `audit_log`); documents are metadata-only (no storage vendor, D31 open; nothing writes `min_phase`/member `phase`); rail census drift (code 7/26 vs docs 7-phase lifecycle vs target 5/65 — the H/V canon ledger `docs/superpowers/specs/2026-07-07-horizontal-vertical-canon-design.md` specifies `tools`/`roles` fields `RailStep` lacks); per-party rail views hardcoded in `perspective/access.ts` instead of derived from `deal_memberships.deal_role`; `ndas`/`compliance_events`/`notifications` tables explicitly deferred (`20260604100000_permissions_schema.sql:4-5`).

## What the rails vision can reuse / must replace

Target: horizontal rails timeline as the core surface — 5 phases, 65 steps, a gate-0 wizard, vertical skills hanging off each step.

**Reuse as-is (don't touch):**
- The token architecture wholesale — palette × style-mode matrix, on-dark fill/stroke ladder, light-mode alias remap, elevation/radius/spacing systems (`src/app/globals.css`). Re-skin values, never rebuild plumbing.
- The contrast contract + `@layer components` semantic ramp — keep new rail classes layered or invisible-text bugs return.
- The motion system (`src/components/_shared/motion.ts`): Skill-Transform Stream is the natural "skill attaches to a step" animation; Compliance Pulse + Score Reveal transfer directly; reduced-motion discipline is universal.
- `ComplianceRibbon` + `CommandBar` + the single-instrument `SET_COMPLIANCE` dispatch pattern — contract-frozen and test-covered; per-step compliance must route through this one ribbon, exactly per the invariant.
- The `ConductiaAPI` seam + deterministic scoring + `screenMessage` rule pack + all analysis panels (football field, culture radar, synergy, founder read) — these ARE the vertical-skill output surfaces; `SkillRunData`'s dataKind→panel mapping (ADR-0005) is the render contract for skills attached to steps.
- The orchestration spine end-to-end (`src/lib/orchestration/` — Job, envelope, gates, supervisor, TokenMeter, audit replay; 44 tests). "Run a skill on a step" = mint a `Job`; extend `selectWorkflow()` per step. `TeaserRunner` is the proof it works in-browser.
- The `/api/v1` platform spine + Supabase schema — deals/memberships/documents/audit + append-only audit + legal hold + `phase int` and `min_phase` columns already think in phases. `FixtureDeal` was built to make the API swap mechanical.
- Atoms (Button/Badge/Pill/Card/ScoreDial/SegmentedControl) and `StageStatus` — extend, don't replace.
- Test infra: constants-schema-sync, api-v1-access, orchestration suites, and the golden-path pattern all survive; the vitest setup needs nothing new.

**Reuse with surgery:**
- `dealRail.ts` — the `RailPhase/RailStep/AgentFeature` type system, the reality-vs-derived-state split, cursor helpers, and `stepAgentFeatures()` precedence are exactly the right shape. But: re-census 7/26 → 5/65 from the H/V canon ledger; add typed `tools`/`roles` (ledger schema) and a typed `skillId` replacing the free-text `skill:` label — unifying the three vocabularies (rail step ↔ seam `Skill.id` ↔ workflow name) is the single most important data change.
- `DealRail.tsx` Focused view logic (cursor, done-summary, mark-complete) — keep the semantics, replace the vertical rendering.
- `TeaserRunner` + `AgentFeatureModal` — two divergent prototypes of "run an agent on a step"; collapse into ONE canonical step-runner surface (loader → artifact → compliance verdict → audit line) backed by the spine, with canned features as the degraded mode.
- The league table in `acquirers/page.tsx:301-665` — extract into a reusable `DataTable` before the rail needs per-phase step tables.
- `/insight/[company]` create flow — the codename wizard (mask validation, deterministic suggestions, `createDeal`) is the seed of the **gate-0 wizard**; rehost it as rail step 0 and back it with `POST /api/v1/deals` instead of localStorage.
- Sidebar/TopBar shell — keep, but add the Rail as the primary destination (or make it home), wire the inert Logout to `supabase.auth.signOut()` (currently stranded in `ProfileMenu.tsx:66-71`), and delete `AppNav`'s divergent list.

**Replace / net-new build:**
- **The horizontal timeline primitive family** — nothing horizontal exists: track/station/connector components, horizontal scroll-snap or pan/zoom container, phase-lane headers, minimap/progress scrubber, step-node states. Core new component work.
- **Persisted rail state** — a `deal_steps`/`rail_progress` table (per-step status, timestamps, owner, completion evidence) replacing the localStorage cursor; plus the Supabase-backed `JobStore` so runs and token spend land in `audit_log`.
- **A skills/workflows registry keyed to step ids** — today there is 1 workflow skeleton for 26 steps; `STEP_FEATURES` is the seed data but is untyped against the spine.
- Density primitives for 65 steps — compact list rows, virtualization, collapsed-phase affordances beyond `<details>`; Tooltip/Popover/Modal/Drawer real primitives (Radix is installed but only used in the throwaway demo).
- Status-badge unification — render `reality` (live/schema/planned, currently invisible) and derived state as `Badge` tones, not ad-hoc spans.
- One icon system (three dialects today; the 7-glyph brand set has no step/skill/agent/document glyphs).
- Per-party rail visibility derived from `deal_memberships.deal_role` + `phase`, replacing the hardcoded 3-persona `perspective/access.ts`.
- Kill list: `shell/AppRail.tsx`, `HomeHero.tsx`, `SidebarWithSubmenu.tsx`, `ui/demo.tsx` (+ its Radix deps if unneeded), Fraunces font load (unreachable), legacy `mandateCompany`/`SET_MANDATE`, the landing `--l2-*` dialect (formalize as a marketing skin or fold in).
- Resolve the home question: the Mandate dashboard and the rail both claim "where the deal stands" — under the rails vision the rail owns home and the dashboard becomes a vitals panel/step artifact.
- Add what zero tests cover today: contrast-contract/palette pinning, and rail-state persistence tests once the table exists.
