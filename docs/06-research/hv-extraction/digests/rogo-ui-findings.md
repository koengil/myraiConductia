# Rogo UI/UX Findings

Visual-source analysis for the Conductia redesign. Sources: 10 app screenshots (`rogo-research/screenshots/Screenshot 2026-07-07 at *.png`), 10 product/marketing images (`rogo-research/webarchive-assets/`), and the captured app-home + changelog page (`rogo-webarchive.html`). Every finding is tagged with its source file. Descriptions are strictly what is visible/present in the sources.

---

## Layout system — regions, panels, density, grid, chat-vs-workspace balance

- **Two-region shell: one fixed left rail (~270px) + full-bleed content.** No top nav bar. The rail holds brand, "New Chat", nav list, pinned/projects/history sections, and the account block; everything else is content. (`Screenshot 9.46.18 AM.png`, `9.47.05`, `9.55.53`) A collapse control sits next to the wordmark, with a dark tooltip "Click to collapse ⌘B" (`rogo-webarchive.html`).
- **Chat renders as a document, not a widget.** Answers are a single readable column (~900px max-width) with generous line-height, real headings, bold-led bullets — no chat-bubble chrome on assistant turns. Only the *user* message gets a bubble (light gray, right-aligned). (`9.55.53`, `9.58.08`)
- **Contextual third panel appears only when earned.** In a chat with citations, a right-hand "5 Sources" panel lists favicon + title + domain rows. It is absent otherwise. (`9.52.47`)
- **Workspace surfaces go edge-to-edge.** The Tables grid uses the full width with a toolbar row (Run Table / File / Edit / Help / Add Rows / Add Column / Schedule left; view-density toggles + Export right) and a bottom status bar ("● 1 Processing · <1 min remaining"). (`9.46.18`)
- **Chat + artifact split when a deliverable exists:** chat pane left (~1/3, with prompt pill, timing chip, source chip, summary bullets, artifact card) and full spreadsheet viewer right (~2/3) with an Excel-style ribbon and formula bar. (`sheets-agent-banner.png`) In Excel itself the ratio inverts: artifact dominant, Rogo as a right taskpane. (`excel-plugin-wide.jpg`)
- **Home is an empty-state hero:** centered serif greeting ("What can Felix do for you?"), one large rounded composer card with its controls *inside* the card footer (attach, source scope left; tier picker + submit right), and a row of quick-action pills below (Create ⌄, Connect Apps with Notion/Box/Dropbox mini-logos, Schedule, Public Documents). (`9.48.48`, `9.49.19`, `rogo-webarchive.html`)
- **Faint graph-paper grid texture** behind the home/marketing composer surfaces — barely-visible hairlines crossing the canvas, in both light and dark. (`updated-home-screen.jpg`, `dark-mode.jpg`)
- **Density model: small type, airy space.** Base UI text is 12px/18, secondary 10.5px/15, micro-labels 9px/12 (`rogo-webarchive.html` CSS) — yet screens feel calm because of hairline dividers, tall rows, and wide margins rather than boxes. (`9.47.05`, `9.46.18`)
- **Overlays are layered, not routed:** column-config popover anchored to its column (`9.46.18`), two-level cascading source tray (`9.49.19`), centered share modal dimming the thread (`9.52.47`), and the changelog as a full overlay panel with its own internal timeline gutter (`9.34.51`).

## Navigation & IA — nav elements, home-screen IA, projects, how users move

- **Rail order (top→bottom):** New Chat button → Home, Search, Tables, Skills, Library, Scheduled Tasks, Shortcuts → "Pinned" (drag-to-pin affordance) → "Projects" (e.g. Project Compass) → "History" → What's new, Help & Support → avatar + name with notification-bell and download icons. (`9.46.18`, `9.47.05`, `rogo-webarchive.html`)
- **History is a heterogeneous artifact stream**, not just chats: a table ("Untitled Table", grid icon), a scheduled automation ("Daily Brief: Top AI In…", bell icon), and chats (speech-bubble icons) interleaved, each typed by icon. Captured history includes M&A-native items: "Process Letter Review Request", "Waterfall Analysis Vs Term Sheet", "M&A Closing Timeline Additions". (`9.46.18`, `rogo-webarchive.html`)
- **Workspaces use breadcrumbs ("Tables › Untitled Table"); detail pages use back-chevron + title** with page actions top-right (Run / Share / Remix on a skill). (`9.46.18`, `9.47.39`)
- **Projects = deal workspaces.** The Projects card shows: folder icon + serif project name ("Project North"), a file-count chip with Excel/Word/PowerPoint mini-icons + "24 Files", a scoped "New Chat in Project" input, recent artifact rows (chat + presentation icons: "Diligence review summary: key outstanding items", "Valuation considerations: selected publicly traded peers"), and PDFs being dragged in. (`projects-preview.png`) The changelog frames Projects explicitly for sell-side: "Running a sell-side process? You need instant access to your financial model, call notes, marketing materials, and legal documents…", with persistent per-project instructions and bulk dataroom upload. (`rogo-webarchive.html`, Jan 2026 entry)
- **Keyboard-first movement is taught in the UI itself:** placeholder copy "Type / for shortcuts…" (`9.48.48`) and "Press ⌘⇧O for a new tas…" (`9.49.19`); documented shortcuts `/` (shortcut dropdown), Ctrl+I (prompt optimizer), Ctrl+\ (model toggle), Ctrl+K (new chat), ⌘B (collapse rail). (`rogo-webarchive.html`, Oct 2025 entry)
- **Onboarding as inline cards, not tours:** home shows dismissible setup cards — "Connect two apps to Felix / Felix works best with two or more tools connected / Connect" and "Claim Felix email access / …start emailing tasks from anywhere / Claim Email". (`rogo-webarchive.html`)

## Design language — color, type, spacing, radii, components; polish details worth stealing

**Color (light).** Canvas `#fcfdfb` warm off-white; panels `#f9f9f7` / `#f2f2f1` / `#eae9e7`; ink `#151312`, secondary `#34312e/#34312d`, muted `#655e59`, placeholder `#97918d`; dark tooltip `#1f1c1b`. One accent: deep forest green `#134a34`, used *only* for primary buttons, toggles, selection borders, links, focus rings, and citation/range chips. Red appears solely on destructive menu rows ("Delete column") and third-party logos. (`rogo-webarchive.html` CSS; visible throughout `9.46.18`, `9.47.05`, `9.48.48`)

**Color (dark).** Near-black *warm* dark (not blue-black), same faint grid, subtle-border input card, and the identical green accent on the submit button — the brand color survives theme inversion unchanged. (`dark-mode.jpg`) Dark is positioned as "built for long hours and low-light workflows". (`rogo-webarchive.html`, Oct 2025)

**Type.** Serif display "Martina Plantijn" for greetings, page titles, feature/changelog headings (22.5px hero, 18px titles, 15px section H2s, 13.5px H3s); "Inter Variable" for all functional UI (12 / 10.5 / 9px tiers). (`rogo-webarchive.html` CSS; serif visible in `9.47.05` "Skills", `9.48.48` greeting, `9.34.51` "Slide Annotations", `projects-preview.png` "Project North")

**Radii & elevation.** Large radii (~12–16px) on cards, popovers, and the composer; ~8–10px on buttons/inputs; full pills for filter chips and quick actions; iOS-style toggle switches. Elevation is minimal — soft single shadows on popovers/modals, hairlines elsewhere. (`9.46.18`, `9.48.48`, `updated-home-screen.jpg`)

**Component grammar.**
- Buttons: filled dark-green primary with white text ("Run Table", "Save", "Create Skill", "Copy Link", "Remix"); white outlined secondary ("Help", "New Chat"); ghost text menus (File/Edit/Help); red text reserved for destructive. (`9.46.18`, `9.47.05`, `9.52.47`)
- Chips/badges everywhere: column-type icon chips ("T" text), inline code chips (`{number}`, gray bg, mono — `9.47.39`), green-tinted mono range chips ("LBO C8:D26" — `excel-plugin-wide.jpg`), source chips with logos (AAPL, 10-K, 10-Q, Earnings Calls — `tables.jpg`), file-count chip ("24 Files" — `projects-preview.png`), attribution chips ("By Rogo" — `9.47.05`).
- Tables: quiet hairline grid, tall rows, cell selection = 2px green border; loading cells show skeleton bars with a pulsing green dot. (`9.46.18`, `tables.jpg`)
- Cards: skill cards = icon tile + bold name + 2-line gray description + attribution + per-card toggle, separated by hairlines in a 2-column list. (`9.47.05`)

**Polish details worth stealing.**
- Timing receipts on every agent turn: "Worked for 31s ›", "Worked for 46s ›", collapsed "3 steps completed ›". (`9.55.53`, `sheets-agent-banner.png`, `9.52.47`)
- Live status bar: "● 1 Processing · <1 min remaining". (`9.46.18`)
- In-cell citation corner-triangle markers, with hover provenance card. (`cell-citations.jpg`)
- Numbered annotation badges + green highlight region + floating annotation toolbar (comment / pencil / marquee) on slides, with a dark inline instruction popover ("Add % Growth bubbles / Cancel / Add"). (`9.34.51`)
- Composer submit button becomes a stop (square) during streaming. (`9.58.08`)
- Placeholder copy that teaches shortcuts; dark kbd-hint tooltips. (`9.49.19`, `rogo-webarchive.html`)
- Marketing/banner surfaces use dark blurred photography of suited figures; the app itself is entirely flat and photography-free. (`projects-preview.png`, `new-models.jpg`, `rogopro.jpeg` vs all app screenshots)

## Interaction patterns — skills, model pickers, source selection, citations, tables/artifacts, states

- **Skills are a governed, org-distributed library.** Gallery: All/Organization filter pills, search, grid/list toggle, per-skill enable toggles, "By Rogo" authorship. (`9.47.05`) Detail page: icon + H1 + master toggle, description written as a *routing trigger* ("ALWAYS load this skill when the user asks to build… a list of acquisition targets… on a buyside mandate"), metadata row (author, date "Jun 11, 2026", scope "Organization"), Instructions/References tabs, and Run / Share / Remix actions. The instruction body is rendered markdown in a resizable gray panel, and encodes MD-grade judgment: "pause and ask one short clarifying message before running screens. This is the difference between a generic list and a list an MD would actually send to a client." (`9.47.39`)
- **Tiered agent picker, plain-language descriptors.** "Felix ▪ Auto / Max / Medium / Light", each with one line of best-for text ("Most capable for full deliverables", "For faster analysis, drafting, research"), checkmark on the active tier, and a "More models ›" escape hatch exposing raw vendor models (Opus 4.8/4.7/4.6, Sonnet 4.6, GPT-5.5/5.4/5.4 Mini, Gemini 3.5 Flash/3.1 Pro/3 Flash) with vendor icons. (`9.48.48`) The earlier generation was task-shaped rather than model-shaped: Instant ("No external sources") / Rogo Fast ("Quick answers <30 sec") / Rogo Pro ("Thorough answers 2–5 min") / Deep Research ("Long searches & reports 10+ min"). (`updated-home-screen.jpg`, `new-models.jpg`, `rogo-webarchive.html` Sep 2025 table)
- **Source scoping is a first-class pre-send control.** From the composer's "All sources" control: a category tray — External Sources (master toggle), Internal Sources ("Add"), Broker Research (toggle), plus "Manage connectors" — cascading to a searchable per-source toggle list with logos: Earnings, SEC Filings, Investor Presentations, Web, PitchBook, Capital IQ, Crunchbase, International Filings, UK Companies House. Internal vs external is structurally segregated. (`9.49.19`)
- **Citations are bidirectional provenance.** Prose answers get a right-hand numbered Sources panel (`9.52.47`). Spreadsheet hardcodes get in-cell citations: hovering a green-marked cell opens a card with company logo, name, ticker/exchange ("NVDA ▪ NASDAQGS"), a mini statement table with the cited figure highlighted, the source chip ("S&P Capital IQ"), and "View source ↗". (`cell-citations.jpg`) Narrative-to-artifact linkage uses range chips: "1. Transaction & Financial Assumptions [LBO C8:D26]". (`excel-plugin-wide.jpg`)
- **Agent work is narrated, then collapsed.** During a Tables run, an overlay shows "Researching…" with streamed first-person reasoning, then labeled search scopes ("Searching AAPL filings") with source chips, and "Identified company" checkpoints; the grid cells skeleton-load meanwhile. (`tables.jpg`) Finished work collapses to "N steps completed ›" and "Worked for Ns ›" receipts. (`9.52.47`, `9.55.53`)
- **AI Tables = prompt-per-column grid.** Each column has a name, Answer Type (Text), Inputs (typed chip referencing another column), Data sources ("Earnings, SEC Filings + 10"), and a full prompt textarea, plus sort/re-run/duplicate/delete; tables can be Run and Scheduled, rows/columns added inline, exported. (`9.46.18`)
- **Composer context chips carry selection into the prompt:** in the Excel taskpane the composer is headed "B2 | Selected", with follow-up field "Ask for follow up edits…" and a local model label ("Opus 4.7 ⌄"). (`excel-plugin-wide.jpg`)
- **Artifacts are embedded cards in chat:** "Apple P&L 2020 to 2023 / Spreadsheet ▪ 1 sheet" with a download icon, opening the full viewer. (`sheets-agent-banner.png`)
- **Sharing includes an access disclosure.** Share modal = link field + green Copy button + a lock-icon panel: "Who can access this link? Authenticated members of your organization with the link can view this thread, including future messages. Private uploaded files are not shared with recipients." (`9.52.47`)
- **The assistant voice is candid about boundaries** — answers privacy/cost questions with "the honest boundary": admin/compliance access "is determined by your firm's contract and configuration, not something I can see or guarantee", and routes to account team / trust docs. (`9.55.53`, `9.58.08`, `9.58.46`)
- **Prompt Optimizer:** one-click Before → "✨ Improved" rewrite of a weak query into a structured analyst prompt. (`prompt-optimizer.jpg`)
- **Memory is user-inspectable:** "Settings → Memory to view everything Felix has stored, edit individual entries, or clear memories." (`rogo-webarchive.html`, May 2026)

## What to steal vs skip for Conductia

Frame: Conductia's thesis is decisions-not-data for an MD, with compliance as the moat and the rails timeline as the core surface. Rogo is the analyst-grade counter-reference — steal its *trust plumbing and restraint*, skip its *open-ended analyst grammar*.

**Steal**

1. **Single-accent discipline.** Rogo runs an entire enterprise app on warm neutrals + one deep green reserved for action/selection/provenance (`rogo-webarchive.html` palette, `9.46.18`). Map directly: navy canvas + neutrals, with **gold held to the same narrow duty** — primary actions, selection, compliance-cleared provenance marks. Nothing else gold.
2. **Serif-display / sans-UI split.** Martina Plantijn for greetings/titles, Inter for everything functional (`9.48.48`, `9.47.05`) validates the existing Fraunces/Inter pairing — keep serif ceremonial (mandate name, destination titles, timeline milestones), never in controls.
3. **Receipts as compliance surface.** "Worked for 31s ›" / "3 steps completed ›" / "● 1 Processing" (`9.55.53`, `9.52.47`, `9.46.18`) is the exact grammar for audit visibility: every AI-assisted step on a mandate should collapse to an expandable receipt — "Screened · KYC ✓ FINRA ✓ MNPI ✓ · 12s ›" — on the rails timeline itself. This turns the compliance moat into visible, clickable UI.
4. **Hover provenance cards on every number.** The in-cell citation card (`cell-citations.jpg`) — marker → card → source chip → "View source" — should apply to acquirer composite scores (Anthropic 87) and every screened datapoint. Deterministic scoring + provenance card = defensible in front of a client.
5. **Range-chip linkage between narrative and artifact** ("LBO C8:D26", `excel-plugin-wide.jpg`): use the same pattern to pin console answers to rails-timeline entries, acquirer cards, or document sections ("Mandate › Milestone 3").
6. **Share-with-disclosure.** The plain-language "Who can access this link?" panel (`9.52.47`) is compliance-first sharing done right — every Conductia share/export should state audience + audit consequence in the same breath as the Copy button.
7. **Source perimeter as visible control — but gated.** Rogo's external/internal source tray (`9.49.19`) becomes Conductia's *information perimeter*: show exactly which sources may inform this mandate, with internal sources locked behind compliance approval rather than a self-serve toggle. The structural External/Internal segregation is already the right skeleton.
8. **Skills as governed org library.** Card grammar, trigger-style descriptions, Instructions/References tabs, org scoping (`9.47.05`, `9.47.39`) map onto the Skills destination — swap the self-serve enable toggle for an approval state (Proposed → Compliance-approved → Active). Note Rogo already ships sell-side M&A skills (Buyer List, CIM Executive Summary Builder) — Conductia's differentiation must be the decision framing, not the skill list.
9. **Project-picker card grammar.** Folder + serif deal name + file-count chip + recent-artifact rows (`projects-preview.png`) is a ready template for the `/` project picker.
10. **Mixed-artifact history + typed icons** in the rail (`9.46.18`) — the rail's history should interleave threads, screens, and scheduled checks, each typed.
11. **Timeline gutter grammar from the changelog** (`9.34.51`): date marker + hairline spine + serif entry title + content card is precisely the rails-timeline visual skeleton — date-anchored, left-gutter, generously spaced.
12. **Micro-polish set:** placeholder copy that teaches shortcuts, kbd tooltips, ⌘K/⌘B culture (`9.49.19`, `rogo-webarchive.html`), submit→stop morph while streaming (`9.58.08`), skeleton cells with pulsing accent dot (`tables.jpg`), inline setup cards instead of tours (`rogo-webarchive.html`) — reframe the setup cards as gate nudges ("Complete KYC screen to open this mandate").
13. **Candid-boundary voice** (`9.55.53`, `9.58.46`): statements, honest limits, routes to the accountable human. Matches Conductia's senior/precise/decisive brand voice; adopt for compliance messaging especially.

**Skip**

1. **Chat-as-home.** Rogo's center of gravity is an open composer ("What can Felix do for you?", `9.48.48`). Conductia's home is the mandate/rails, with the command console floating and secondary — do not let the composer become the landing surface.
2. **Raw model exposure.** The "More models" vendor list (Opus/GPT/Gemini, `9.48.48`) is analyst catnip and MD noise. Hide model plumbing entirely; at most one depth control with plain-language descriptors (the older Instant/Fast/Pro/Deep Research task-shaped naming in `updated-home-screen.jpg` is the better pattern if any control survives).
3. **Prompt-per-column AI Tables as a primary surface** (`9.46.18`, `tables.jpg`). This is a data-dump factory — exactly the Rogo posture Conductia rejects. If screening grids exist at all, they live behind an analyst/back-office door, pre-shaped into decisions before an MD sees them.
4. **Self-serve source toggling without governance** (`9.49.19` as-is) — perimeter changes on a live mandate must route through the compliance instrument, not a hover tray.
5. **Prompt Optimizer as a feature** (`prompt-optimizer.jpg`) — MDs shouldn't need prompt craft; the intake and skills should absorb that burden invisibly.
6. **Photography in-product.** Rogo confines blurred-banker photography to marketing (`rogopro.jpeg`, `new-models.jpg`); the app is flat. Conductia should hold the same line — the navy+gold system carries the gravitas, no stock imagery.
7. **Grammarly-style third-party overlays** visible in captures (`9.48.48`) — incidental, but a reminder to keep the console clean of injected chrome.
