Modeling & Valuation 16

3-Statement Model

Rogo built-in

Build, populate, or update a fully integrated 3-statement financial model (Income Statement, Balance Sheet, Cash Flow Statement) in Excel. Use this skill when asked to model a company, build a financial model, create a client-ready integrated model, fill out a model template, or link financial statements within an existing structure (LBO, DCF, etc.). Also trigger when asked to create supporting schedules (PP&E, working capital, debt) that feed into a 3-statement framework, or when asked to add scenario/case toggles to a financial model. Do NOT use when the user requests only an LBO, DCF, or operating model without specifically asking for a full 3-statement model.

Rogo built-in

Use when building a discounted cash flow (DCF) valuation model in Excel. Covers unlevered free cash flow projections, terminal value (exit multiple and perpetuity growth methods), WACC analysis with comparable company betas, CAPM cost of equity, equity bridge to share price, and sensitivity tables. Trigger this skill whenever the user mentions DCF, discounted cash flow, intrinsic valuation, WACC analysis, terminal value, company valuation, stock valuation, what a company is worth, fair value estimate, or building a financial model from scratch — even if they don't explicitly say 'DCF.' Also trigger when the user asks to value a public or private company, estimate a share price target, or build a valuation from first principles.

LBO Model

Rogo built-in

Use when building a leveraged buyout (LBO) model in Excel. Covers transaction mechanics (sources and uses, entry valuation, financing assumptions, pro forma capital structure), operating model build (income statement with drivers, cash flow, balance sheet), debt schedules with circularity handling, returns analysis (IRR, MOIC, returns attribution), sensitivity tables, and a one-page IC summary output. Trigger whenever the user mentions LBO, leveraged buyout, buyout model, PE model, private equity returns, take-private, sponsor returns, debt paydown model, or asks to model an acquisition with leverage — even if they don't say 'LBO' explicitly. Also trigger when the user asks to calculate IRR/MOIC on a leveraged transaction or build a sources and uses table. For a standalone debt schedule without the full LBO build, use lbo-debt-schedule. For modeling a dividend recapitalization on top of an LBO, use dividend-recap. For modeling a sale-leaseback transaction, use sale-leaseback.
