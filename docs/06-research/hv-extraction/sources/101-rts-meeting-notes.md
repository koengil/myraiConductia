Platform Vision and Agent Architecture
	•	Storm’s framing: 82-step sell-side process, each step is an “application” (human, agent, or hybrid)
	◦	McDonald’s analogy: componentize the process, allocate each piece to a specialist (robot or human), assemble at the end

	•	Agent autonomy vs. compliance is the central tension
	◦	Agents must check other agents’ work before output reaches the user
	◦	Trust collapses immediately if errors reach the banker
	•	Gradual automation model: start ~80% human / 20% agent, expand over time
	•	Network effect built into the business model: buyers, sellers, lawyers, accountants all eventually on platform
